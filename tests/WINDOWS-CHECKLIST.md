# Windows 桌面实机验收

目标环境：Windows 11 Enterprise 10.0.26200 x64。Windows 10、混合 DPI 与多屏尚未验收。

自动测试和句柄挂接检查不能替代下面的物理交互。每次验收填写 PROGRESS 中日期、环境、结果、问题和复现步骤。

- [x] C++ 桥接编译；本机 Electron parent 句柄返回桌面挂接成功。
- [x] 普通窗口中编辑器获得键盘输入；UI/CLI 更新一致；重启后持久化。
- [x] 主屏125%、第二屏100%的混合DPI区域检查：第二屏可用区域1920×1032与窗口物理区域一致。
- [x] HKU启用后真实订阅成功45条；重复刷新保持45条；UTC课程使用HKT显示。
- [ ] 打开其他软件，日历被遮挡且不抢焦点。
- [ ] Win+D 显示、再次 Win+D 恢复软件，日历仍在桌面。
- [ ] 点击日期、拖动改期；区域外图标双击、拖动及桌面右键正常。
- [ ] 桌面模式打开编辑窗口，中文输入法、Tab、保存正常。
- [ ] 锁屏解锁、睡眠恢复、显示器拔插和缩放后恢复。
- [ ] Explorer 重启后恢复；旧窗口句柄失效时正确降级或重建。
- [ ] 安装器 PATH 选项、实际安装/升级/卸载保留数据。
- [ ] 连续使用至少7天并记录空闲 CPU、内存和月份切换性能。
- [ ] 用户配置模型后的中文真实 AI 查询、添加、改期验收。

禁止为了测试直接让用户电脑进入睡眠、锁屏或重启 Explorer；这些项目由用户安排合适时机执行。
